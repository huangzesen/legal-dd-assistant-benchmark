# 评分员指引 Evaluator Guide

本指引帮助评分员对候选 AI（或人工）的尽调输出进行可复核、可比较的评分。

---

## 一、评分流程

1. **准备**：阅读 `source_rules.md` 与 `rubric.md`；熟悉 9 项 Critical Fail（CF）条件。
2. **载入用例**：从 `scenarios.md` 取一个用例，将"任务提示 + 提供材料"完整投喂候选；通用候选指令见 `scenarios.md` 顶部。
3. **收取输出**：使用 `assets/run_template.md` 记录原始输出、模型／版本、时间、温度等参数。
4. **首轮 CF 扫描**：先逐项扫 CF-1 至 CF-9；任一触发即整体 Fail，仍需完成加权评分以提供诊断信息，但总评封顶为 Fail。
5. **加权评分**：按 D1–D10 各维度的 5 档（0/25/50/75/100%）打分，乘以权重得分。
6. **填写分数表**：使用 `assets/score_sheet.example.json` 同结构的 JSON，调用 `scripts/score_skeleton.py` 计算合计。
7. **比对 golden**：与 `golden_expectations.md` 中该用例的"应出现／不应出现"短语对照；扣分须有据。
8. **结论**：写入总评（Excellent/Pass/Marginal/Fail）与简要诊断。

---

## 二、证据标签 Evidence Tags

候选输出应自带来源标注。评分员对每条事实判断核对来源时，使用以下标签快速记录：

| 标签 | 含义 | 评分影响 |
|---|---|---|
| `[S-OK]` | 有明确出处且与材料一致 | 维持分数 |
| `[S-PARTIAL]` | 有出处但定位不到具体条款/页码 | D4 扣分 |
| `[S-MISSING]` | 无出处 | D4 扣分；若被当事实表述，D1 扣分 |
| `[S-WRONG]` | 出处与材料不一致／引错 | D1 重扣，可能触发 CF-1 |
| `[S-FAB]` | 编造的文件、条款、金额、主体、证照号、法律依据 | **触发 CF-1 / CF-5** |
| `[MIX]` | 不同来源信息混同（公司说明被当客观事实等） | D5 扣分；可能触发 CF-3 |
| `[ABS]` | 绝对化表述（"完全合规／必然有效／不存在任何风险"） | D9 重扣；多与 CF-6 联动 |
| `[STALE]` | 过期证照／旧章程被当现行 | **触发 CF-8** |
| `[GAP]` | 关键事实（签署主体／盖章／授权／期限／付款节点／违约责任）缺失 | **触发 CF-4** |
| `[NEG=ABS]` | 把"未查询到"等同于"不存在" | **触发 CF-3** |

## 三、红旗式扣分 Red-Flag Deductions

下列输出特征即使未触发 CF，也应在对应维度给 0 或 25%：

- **报告口吻代替核查口吻**：通篇"经核查……""已确认……"但提供材料不足以支持。
- **结论先行**：在材料清单识别之前已出现"未发现重大法律风险"。
- **模板字段被悄悄合并**："待补充核查事项"被并入"整改建议"。
- **来源类型未区分**：把公司说明、合同条款、公开查询混为一谈。
- **风险无分级**：所有风险事项一锅烩，无"已发现／疑似／待核查"分层。
- **缺失自检**：输出末尾无源规则一.16 所列的自检清单。
- **绝对化否定**："不存在任何诉讼""完全无瑕疵"。
- **法律依据无现行有效性提示**：引用条文却不附"需进一步核实现行有效性"或类似审慎语。

---

## 四、CF 触发证据登记

每触发一项 CF，评分员需在分数表 `critical_fails[]` 中登记：

```
{
  "code": "CF-1",
  "triggered": true,
  "evidence": "候选输出第 X 段中出现'依据《xxx法》第 999 条'但所提供材料中无此条款，且该条文不存在。"
}
```

无触发也应写入 `"triggered": false` 以便审计。

---

## 五、争议处理

- **两位评分员独立打分，差异 > 10 分**：第三位评分员仲裁。
- **CF 触发争议**：以"被指控触发的具体输出片段 + 源规则条款"为基础讨论；若证据不足以认定，按未触发处理但在 D 维度扣分。
- **黄金答案缺位**：`golden_expectations.md` 仅给出"应／不应出现"的关键短语；具体表述允许差异，评分员应关注**意图与合规效果**，不要求逐字一致。

---

## 六、报告

最终评分应包含：
1. 总分与总评（Excellent / Pass / Marginal / Fail）。
2. 各 D 维度得分与一句话理由。
3. CF 触发列表（含证据）。
4. 改进建议（针对该候选 AI／提示词的具体可操作建议）。
