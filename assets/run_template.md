# 运行记录模板

> 每次对一个候选（AI 模型或人工）的一个用例运行时填写一份。可保存为 Markdown 或转换为 JSON。

---

## 元数据

- **运行 ID**：`RUN-YYYYMMDD-HHMM-<scenario_id>-<candidate_id>`
- **用例编号**：用例 X（见 `reference/scenarios.md`）
- **候选名称 / 版本**：例如 `Claude Opus 4.7` / `GPT-x` / `人工律师 A`
- **调用参数**：temperature、top_p、max_tokens、system_prompt 摘要
- **运行时间**：UTC ISO8601
- **评分员**：姓名 / 编号
- **耗时**：候选生成耗时 / 评分耗时

---

## 输入

### 系统提示
（贴入投喂给候选的系统提示词；通常包含 `reference/source_rules.md` 的全部或核心条款）

### 用户提示 + 材料
（贴入用例的"任务提示"与"提供材料"原文）

---

## 输出

### 候选原始输出
（完整贴入，不要截断）
